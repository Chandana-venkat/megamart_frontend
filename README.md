# 🛒 MegaMart - E-Commerce Website

MegaMart is a full-stack e-commerce web application developed using React.js, Redux Toolkit, Bootstrap, and JSON Server.  
This application provides online shopping features like product browsing, searching, cart management, wishlist, checkout, and order management.

---

## 🚀 Features

## 👤 User Features

- User Registration
- User Login and Logout
- Browse products
- Search products
- View product details
- Add products to cart
- Update cart quantity
- Remove products from cart
- Add products to wishlist
- Checkout functionality
- Place orders
- View order history


## 🛍️ Product Features

- Category based products:
  - Men's
  - Women's
  - Beauty
  - Home Living
  - Gen Z

- Product details:
  - Product image
  - Product name
  - Price
  - Discount
  - Rating
  - Reviews
  - Stock details


## 🔐 Authentication

- User authentication using localStorage
- Login session management
- Logout functionality


## 🛠️ Admin Features

- Admin Login
- Add Products
- View Products
- Edit Products
- Delete Products
- Manage Orders

# ⚙️ Installation and Setup

## Clone Repository

```bash
git clone <repository-url>
```

---

## Install Frontend Dependencies

```bash
npm install
```

---

## Install Backend Dependencies

Go to backend folder:

```bash
cd backend
```

Install dependencies:

```bash
npm install
```

---

# ▶️ Run Application

## Start React Application

```bash
npm run dev
```

Frontend runs on:

```
http://localhost:5173
```


## Start JSON Server

Inside backend folder:

```bash
npx json-server --watch db.json --port 3001
```

Backend runs on:

```
http://localhost:3001
```

# 🛒 Application Flow

1. User registers an account.
2. User logs in using email and password.
3. Products are displayed from backend API.
4. User adds products to cart.
5. Checkout page collects shipping and payment details.
6. Order details are stored in JSON Server.
7. User can view order history.


---

# 🔐 Login Flow

1. User enters email and password.
2. Application verifies user details from backend.
3. User information is stored in localStorage.
4. Navbar displays username and Logout option.
